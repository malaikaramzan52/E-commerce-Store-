# Elegance Couture - E-Commerce Store

## Overview
Elegance Couture is a modern and user-friendly E-Commerce website designed for fashion and clothing shopping. The platform provides customers with a smooth online shopping experience along with a powerful admin dashboard for store management.

---

# Features

## User Website Features

### Home Page
- Attractive and responsive landing page
- Featured products section
- Discount banners and promotions
- Trending categories display

### Product Categories
- Multiple fashion categories
- Easy product browsing
- Filter and search functionality

### Shopping Cart
- Add products to cart
- Update quantity
- Remove items from cart

### Wishlist
- Save favorite products
- Manage wishlist items easily

### Place Order
- Secure checkout process
- Order summary before confirmation

### Order Confirmation
- Confirmation message after successful order placement
- Order details for users

### Contact Us
- Users can send queries directly through the contact form
- Emails are received by:
  - Admin Dashboard
  - Admin Gmail Account

### FAQ Section
- Frequently Asked Questions for customer guidance
